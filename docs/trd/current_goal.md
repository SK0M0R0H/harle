# Big goal
Implement three types of use-cases for Harle:
1. Researcher for the company: uses company-related materials from dataset, does a lot of internet search, returns files as a result. 
Exampels of tasks for the role: "Prepare a report on potential privacy solutions for institutionals. The solutions must be aligned with our L2 architecture"; "Calculate paramters (block time, batch time, block size, etc.) fopr our chain in alkignemnt with economic model".

2. Basic Secretary: uses all dataset, does interente search, integrates with Trello, updates dataset based on the new information from trello or a given task, works via chat.
Examples of tasks for the role: "Prepare data input for all Japan trip related tasks", "Find all stalled tasks in Trello, suggest reformulation of the task definition into simplest first step", "Summarize this article based on my preferences"


3. Agents Specialist: uses all dataset, check agents logs, updates dataset, keep dataset versioning, does internet search.  
Exammples of tasks for the role: "Upgrade all dataset .md files with better keywords for search", "Find which pre-processing orchestrator can do before giving tasks to LLMs"
